# RiseAcademy Materials

**`$rise-materials` — skill для Codex, который создаёт, адаптирует и проверяет учебные материалы английского по методике RiseAcademy.**

[Скачать ZIP](https://github.com/Tmmt89/rise-materials/releases/latest/download/rise-materials.zip) · [Skill](skills/rise-materials/SKILL.md) · [Методическая база](skills/rise-materials/references/basis/methodology/README.ru.md)

## Установка

### Через Codex

Отправьте в Codex:

```text
Используй skill-installer и установи skill из
https://github.com/Tmmt89/rise-materials/tree/main/skills/rise-materials
```

После установки skill доступен со следующего сообщения. Можно вызвать его явно: `$rise-materials`.

### Из ZIP

1. Скачайте архив по ссылке выше и распакуйте его.
2. Поместите папку `rise-materials` в каталог skills Codex: обычно `~/.codex/skills/` на macOS/Linux или `%USERPROFILE%\.codex\skills\` на Windows. Если настроен `CODEX_HOME`, используйте его подпапку `skills`.
3. Убедитесь, что файл находится по пути `skills/rise-materials/SKILL.md`, без дополнительной вложенной папки. Отправьте новое сообщение в Codex с `$rise-materials`.

Если skill уже установлен, сохраните свои изменения перед заменой версии. Инструмент `skill-installer` не перезаписывает существующую установку автоматически.

Требуются **Codex и Python 3.10+**. Дополнительные библиотеки Python, доступ к папкам автора и к репозиторию платформы для обычного проектирования материалов не нужны.

## Примеры

```text
$rise-materials Создай урок для двух взрослых A2: договориться о новом
времени встречи. 30 минут онлайн. Нужны план преподавателя, материалы
ученика, ключи/критерии и проверка качества. Достаточно Markdown.
```

```text
$rise-materials Спроектируй курс бытового общения B1: восемь занятий
по 60 минут. Нужны результаты, последовательность, повторение и проверки.
Полные материалы уроков пока не создавай.
```

```text
$rise-materials Проверь приложенный урок: цель, задания, ключи,
время и соответствие RiseAcademy. Дай конкретные исправления.
```

Можно также адаптировать материал под другой уровень, возраст, время или самостоятельную работу. Skill различает программу курса, готовый урок, отдельное упражнение и аудит; объём задаётся запросом.

## Что входит

- 34 общих правила с условиями и исключениями.
- 9 профилей занятий и 7 контекстов курса.
- 10 frameworks/методов и 30 семейств активностей.
- 24 проверки качества, контракт курса/урока и критерии ученика.
- 38 требований платформы и 37 условных способов реализации активностей.
- 264 авторские карточки исследования с сохранёнными ограничениями и происхождением.

Это переносимый снимок **методической спецификации 0.1.0**. Записи загружаются выборочно; вся база не помещается в контекст каждого запроса.

## Границы версии

Включены авторские методические производные материалы. Исходные учебники, персональные планы преподавателей, презентации, видео и исходный код Speaking_livekit не распространяются. Исторические локаторы сохраняют связь с исследованием, но не дают доступа к самим оригиналам. Если конкретное задание требует отсутствующего медиа, понадобится предоставить его или создать и проверить авторскую замену.

Карта RiseAcademy основана на исследованном checkout от ноября 2026 года. Для свежей проверки кода можно подключить свой разрешённый checkout через `RISE_MATERIALS_PLATFORM_REPO` или `--platform-repo`. Без него `platform-check` возвращает `not_configured`; работа production не считается подтверждённой.

Структура skill, выборочное чтение и пробные задания создания/аудита проверены. Реальные педагогические пилоты и учебный эффект ещё не подтверждены. Материал получает собственный QA; установка skill не означает готовность любого будущего урока к проведению.

## Проверка после установки

Из папки установленного skill:

```sh
python3 scripts/query.py status
python3 scripts/query.py get PR-FUNCTIONAL
python3 scripts/query.py source LANG-020
```

На Windows при необходимости используйте `py -3` вместо `python3`. По умолчанию команда читает встроенную базу `references/basis`. Альтернативная локальная база подключается через `RISE_MATERIALS_WORKSPACE` или `--workspace`; явный ошибочный путь не заменяется другой базой молча.

Встроенный [manifest](skills/rise-materials/references/basis/bundle-manifest.json) содержит версию и хеши данных. [Инструкция доступа](skills/rise-materials/references/catalog-access.md) описывает команды, а [выходы по режимам](skills/rise-materials/references/deliverables.md) — критерии завершения.
