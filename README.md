# Rise Method

**`rise-method` — один skill для Codex и Claude Code:** создание, адаптация и проверка учебных материалов английского по методике RiseAcademy.

[Скачать ZIP](https://github.com/Tmmt89/rise-method/releases/latest/download/rise-method.zip) · [Skill](skills/rise-method/SKILL.md) · [Методическая база](skills/rise-method/references/basis/methodology/README.ru.md)

## Установка

Один ZIP и одна папка `rise-method` подходят обоим клиентам. Общий `SKILL.md`, методическая база и Python-скрипт одинаковы; `agents/openai.yaml` содержит только дополнительные метаданные интерфейса Codex.

| Клиент | Личная установка | Вызов |
|---|---|---|
| Codex Desktop / CLI | `~/.codex/skills/rise-method/` или `$CODEX_HOME/skills/rise-method/` | `$rise-method` |
| Claude Code | `~/.claude/skills/rise-method/` | `/rise-method` |

### Codex

Отправьте в Codex:

```text
Используй skill-installer и установи skill из
https://github.com/Tmmt89/rise-method/tree/main/skills/rise-method
```

После установки skill доступен со следующего сообщения. Можно вызвать его явно: `$rise-method`.

### Claude Code

Скачайте ZIP по ссылке выше и скопируйте папку `rise-method` в `~/.claude/skills/`. Для установки только в один проект используйте `.claude/skills/rise-method/` внутри него. Начните новую сессию Claude Code и вызовите:

```text
/rise-method Создай урок для взрослых A2 на 30 минут: перенести встречу.
```

Установка не требует Codex или его `skill-installer`: пакет целиком находится в архиве. Личные и проектные пути, вызов `/имя` и общий формат подтверждаются [официальной документацией Claude Code](https://code.claude.com/docs/en/skills).

### Из ZIP

1. Скачайте архив по ссылке выше и распакуйте его.
2. Поместите папку `rise-method` в каталог выбранного клиента из таблицы. На Windows `~` соответствует папке пользователя: например, `%USERPROFILE%\.claude\skills\` для Claude Code. Для Codex при настроенном `CODEX_HOME` используйте его подпапку `skills`.
3. Убедитесь, что файл находится по пути `skills/rise-method/SKILL.md`, без дополнительной вложенной папки. Вызовите skill командой своего клиента.

Если skill уже установлен, сохраните свои изменения перед заменой версии. Инструмент `skill-installer` не перезаписывает существующую установку автоматически.

Требуются **Codex либо Claude Code и Python 3.10+**. Дополнительные библиотеки Python, доступ к папкам автора и к репозиторию платформы для обычного проектирования материалов не нужны.

Версия 0.2.0 переименована из `rise-materials`. Если старая версия была установлена, сначала сохраните её локальные изменения и настройки; после установки нового имени удалите прежнюю папку из каталога skills, чтобы не было двух автоматически выбираемых копий. Исторический релиз 0.1.0 сохраняется отдельно.

## Примеры

```text
$rise-method Создай урок для двух взрослых A2: договориться о новом
времени встречи. 30 минут онлайн. Нужны план преподавателя, материалы
ученика, ключи/критерии и проверка качества. Достаточно Markdown.
```

```text
$rise-method Спроектируй курс бытового общения B1: восемь занятий
по 60 минут. Нужны результаты, последовательность, повторение и проверки.
Полные материалы уроков пока не создавай.
```

```text
$rise-method Проверь приложенный урок: цель, задания, ключи,
время и соответствие RiseAcademy. Дай конкретные исправления.
```

Можно также адаптировать материал под другой уровень, возраст, время или самостоятельную работу. Skill различает программу курса, готовый урок, отдельное упражнение и аудит; объём задаётся запросом.

В Claude Code используйте те же запросы с `/rise-method` вместо `$rise-method`.

- 10 frameworks/методов и 30 семейств активностей.
- 24 проверки качества, контракт курса/урока и критерии ученика.

- 264 авторские карточки исследования с сохранёнными ограничениями и происхождением.

Это переносимый снимок **методической спецификации 0.1.0**. Записи загружаются выборочно; вся база не помещается в контекст каждого запроса.

## Границы версии

Включены авторские методические производные материалы. Исходные учебники, персональные планы преподавателей, презентации, видео и исходный код Speaking_livekit не распространяются. Исторические локаторы сохраняют связь с исследованием, но не дают доступа к самим оригиналам. Если конкретное задание требует отсутствующего медиа, понадобится предоставить его или создать и проверить авторскую замену.

Карта RiseAcademy основана на исследованном checkout от ноября 2026 года. Для свежей проверки кода можно подключить свой разрешённый checkout через `RISE_METHOD_PLATFORM_REPO` или `--platform-repo`. Без него `platform-check` возвращает `not_configured`; работа production не считается подтверждённой.

Структура skill, выборочное чтение и пробные задания создания/аудита проверены. Для версии 0.2.0 также проверены переносимый ZIP, шесть поведенческих проверок инструмента и фактический вызов `/rise-method` с чтением встроенной базы в Claude Code. Реальные педагогические пилоты и учебный эффект ещё не подтверждены. Материал получает собственный QA; установка skill не означает готовность любого будущего урока к проведению.

## Проверка после установки

Из папки установленного skill:

```sh
python3 scripts/query.py status
python3 scripts/query.py get PR-FUNCTIONAL
python3 scripts/query.py source LANG-020
```

На Windows при необходимости используйте `py -3` вместо `python3`. По умолчанию команда читает встроенную базу `references/basis`. Альтернативная локальная база подключается через `RISE_METHOD_WORKSPACE` или `--workspace`; явный ошибочный путь не заменяется другой базой молча. Старые `RISE_MATERIALS_WORKSPACE` и `RISE_MATERIALS_PLATFORM_REPO` поддерживаются как алиасы.

Встроенный [manifest](skills/rise-method/references/basis/bundle-manifest.json) содержит версию и хеши данных. [Инструкция доступа](skills/rise-method/references/catalog-access.md) описывает команды, а [выходы по режимам](skills/rise-method/references/deliverables.md) — критерии завершения.
