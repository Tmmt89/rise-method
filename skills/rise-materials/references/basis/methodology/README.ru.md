# Методическая база RiseAcademy

Переносимый снимок спецификации 0.1.0. Основной процесс задаёт SKILL.md; каталог читается выборочно через scripts/query.py.

- [Профили](profiles.ru.md), [frameworks](framework-selection.ru.md), [активности](activity-library.ru.md).
- [Паспорт курса и урока](blueprint-contract.ru.md), [общие правила](core-rules.ru.md), [QA](quality-rubric.ru.md).
- [Карта платформы](platform-fit.ru.md), [привязки активностей](platform-bindings.ru.md).
- [Решения и карантин](decisions.ru.md), [карточки](../research/rule-index.ru.md), [traceability](traceability.json).
- [Настольные сценарии](review-scenarios.ru.md), [рецензия спецификации](review-notes.ru.md).

Включены авторские производные правила и карточки. Оригинальные 73 файла, персональные планы преподавателей, видео и исходный код платформы не распространяются. Статус источника и границы вывода сохраняются; реальные педагогические пилоты и production этим пакетом не подтверждаются.
